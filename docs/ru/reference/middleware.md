# Справочник: middleware

Механика, которая находит версии и наследует между ними роуты. Импортируется из корня пакета:

```python
from fastapi_easy_versioning import (
    API_VERSION_KEY,
    VersioningMiddleware,
    rebuild_versioning,
)
```
